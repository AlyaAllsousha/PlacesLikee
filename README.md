Социальное приложение для путешественников, позволяющее отмечать посещенные места на карте, делиться маршрутами, отправлять прямые ссылки на локации и находить интересные места от других пользователей.

---

## 📖 Описание

**PlacesLikee** — это платформа для сообщества путешественников, где пользователи могут:
- Отмечать на карте места, которые они посетили.
- Делиться впечатлениями и фотографиями.
- Находить рекомендации от других путешественников.
- Подписываться на авторов и получать уведомления о новых метках.
- Делиться конкретными местами с друзьями через прямые ссылки.

---

## ✨ Функционал

### 🌍 Для всех пользователей (Гости)
| Функция | Описание |
|---------|----------|
| Просмотр карты | Отображение всех меток на интерактивной карте Yandex MapKit |
| Список меток | Просмотр всех меток в виде ленты |
| Шеринг| Возможность поделиться меткой и открыть приложение по прямой ссылке |
| Создание метки | Быстрое добавление метки без привязки к автору |
| Поиск | Поиск по автору, названиям, тегам |
| Оффлайн-режим | Просмотр кэшированных данных без интернета |
| Сортировка | По авторам, по количеству лайков, по дате изменения |
| Фильтрация | Только с фото / без фото |

### 👤 Для зарегистрированных пользователей
| Функция | Описание |
|---------|----------|
| Личный профиль | История созданных меток, личная статистика |
| Лайки | Возможность оценивать локации других пользователей |
| Избранное | Сохранение понравившихся меток в отдельный список |
| Авторство | Создание меток с привязкой к личному аккаунту |
| Управление | Редактирование и удаление собственных меток |
| Уведомления | Push-уведомления о новых локациях от тех, на кого вы подписаны |

## 🛠 Технический стек

| Категория | Технологии |
|-----------|------------|
| **Язык** | Kotlin |
| **Архитектура** | Clean Architecture, MVVM |
| **UI & Навигация** | Jetpack Compose, Material Design 3, Navigation Compose |
| **Внедрение зависимостей**| Hilt |
| **Асинхронность & Фон** | Coroutines, Flow, WorkManager |
| **Сеть** | Retrofit 2, REST API |
| **Локальные данные** | Room, DataStore Preferences |
| **Облако & Бэкенд** | Firebase (Auth, Firestore, Cloud Messaging), Node.js микросервис (деплой на Vercel) |
| **Медиа & Карты** | Yandex MapKit, Coil, Cloudinary |
